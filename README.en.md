# Monster Prank

A Windows screen prank tool. At the time you set, a monster jumps up from the bottom of the screen and screams. About five seconds later the program exits on its own.

## What it does

<img src="assets/shot-panel.png" width="600" alt="Control panel">

The control panel offers three ways to fire it:

- **Play now** — previews the effect. The program does not exit afterwards.
- **Timer** — preset delays (30 s, 1, 3, 5, 10 minutes), a custom number of minutes, or an exact clock time down to the second.
- **Idle trigger** — arms after nobody has touched the machine for N seconds, then fires M seconds after keyboard or mouse activity resumes.

### Behaviour

- Three seconds after a timer is set, the control panel hides completely and no longer appears in the taskbar.
- `Ctrl + Alt + M` brings the panel back. Doing so does not cancel the timer.
- Closing the panel cancels all timers.
- `Esc` stops playback immediately.
- On a multi-monitor setup, playback covers the primary screen only.

## Using your own footage

Use `选择视频…` on the panel to swap the asset:

- **Video with an alpha channel** — works directly.
- **Green-screen video** — with no alpha channel, the program reads the background colour from the four corners of the frame and asks whether to key it out.
- **Audio** — if an `_audio.wav` with a matching name sits next to the video, that file is used. Otherwise the audio track inside the video is extracted automatically.

## Download and run

Windows 10 and 11. There is no prebuilt macOS package.

1. Download [**MonsterPrank-windows.zip**](https://github.com/AppApp777/monster-prank/releases/latest/download/MonsterPrank-windows.zip) (49 MB).
2. Unzip it and run `MonsterPrank.exe`.
3. `MonsterPrank.exe` reads the `_internal` and `assets` folders next to it, so it cannot be moved out on its own. If double-clicking does nothing, or a black window flashes and disappears, that is usually why.

### On first run

Windows may show a blue box saying **"Windows protected your PC"**. Click `More info`, then `Run anyway`. That message means the program is not code-signed and Microsoft cannot identify the publisher. It does not mean a virus was found.

`SHA256SUMS.txt` is attached to the release if you want to verify the download.

## What it does not do, and how to remove it

- No network access, no auto-start, no registry or system changes, no data collection.
- To uninstall, delete the folder you unzipped. Nothing is left anywhere else.

### From source

Python 3.10+ with Tk, plus:

```bash
python -m pip install Pillow customtkinter av
```

```bash
python monster_prank.py            # open the panel
python monster_prank.py --check    # verify assets and decoder
python monster_prank.py --demo     # play once and exit
```

### Building

```bash
python -m pip install -r packaging/requirements-build.txt
powershell -ExecutionPolicy Bypass -File packaging/build_windows.ps1
bash packaging/build_macos.sh
```

PyInstaller cannot cross-build a macOS app on Windows, so the mac package has to be built on a Mac.

### Things that cost time to find out

- **VP9 with alpha must be decoded by `libvpx-vp9` explicitly.** FFmpeg's native `vp9` decoder **drops the alpha channel silently** — no error, transparent areas just turn black.
- `UpdateLayeredWindow` expects **premultiplied alpha**, and the premultiplication has to happen before scaling, or edges go white.
- The first-frame poster and the panel thumbnail are **not the same image**. The poster must equal frame 0 or playback jumps at the start, but in this asset the monster has not entered the frame yet at frame 0 — only 1.3% of pixels are opaque, so it makes a blank thumbnail.
- `packaging/build_windows.ps1` **must stay pure ASCII.** PowerShell 5.1 reads a BOM-less `.ps1` as ANSI, and one UTF-8 Chinese comment swallows the following newline, commenting out the next line too.
